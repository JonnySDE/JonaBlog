# Carpeta de Imágenes de JonaBlog (Astro)

Esta carpeta (`web/public/images/`) es el directorio estático público para las imágenes de tu blog.

Todo archivo que coloques aquí estará disponible directamente en el navegador bajo la ruta `/images/nombre-del-archivo.ext`.

Por ejemplo:
- `code-aprendizaje.png` -> Disponible en `/images/code-aprendizaje.png`
- `educontrol.png` -> Disponible en `/images/educontrol.png`
- etc.
